- `review-2026-11-14.md`：可直接阅读的审计报告及 44 篇重构队列。

- `p1-p2-rewrite-2026-11-14.md`：剩余 33 篇来源的中文重构、版本纠正、素材与验证范围。
- `media-inventory.json`：1094 个嵌入素材引用的保留、替换或不迁入理由；未采用不等于逐项目视验证。
- `release-assets.json`：56 个去重原文件的来源、公开地址和 SHA-256。
- `sheet-evidence-2026-11-14.json`：DOC-44 两张接线表的公开预览读取及更正。
- `p0-rewrite-2026-11-14.md`：首批 11 篇中文重写的范围调整、站点接入、验证与待实测事项。

本轮结论：保留 3、重写 25、合并 13、归档 3、删除 0；P0 11 篇、P1 20 篇、P2 13 篇。原始统计文件中的 `content_assessment` 保留采集时的“待逐篇核验”，当前结论以 `inventory.json` 为准。

`reviewStatus: reviewed` 仅代表正文编辑审计完成。全部 44 篇来源已改为 `implementationStatus: community-review`，中文重构/合并/归档与英文待翻译入口已存在。各篇 `implementation` 记录实际修改、新稿指纹和验证范围，不覆盖 `sourceReview` 中的飞书原文指纹。没有改动飞书原文。

`community-review` 不表示社区已经确认。收到反馈、完成适用范围内的必要验证后，再决定发布中文并启动英文翻译；当前 `communityFeedback.status` 仍为 `awaiting-feedback`。

## 已知核验缺口

- DOC-08 的一张旧内嵌映射表尚未读取；现行教程改用固件目录与官方 Release。DOC-44 两张表已通过公开浏览器预览读到，API 权限未扩张；原 3V3 功放电源仍待电气验证。
- 56 张采用原图已按素材清单审阅，14 段视频抽样关键帧；DOC-28 三个历史附件不可读且不再采用。未采用图片、完整视频、工程/二进制执行及全硬件没有被宣称为已验证。
- 本地代码对照不能证明线上部署完全一致；生产计费、第三方服务及全板型真机均需另行验证。具体检查记录在每篇的 `publicationChecks`。
- 每篇记录正文 revision 与 SHA-256。完整读取响应仅保存在临时缓存，不把评论、个人访问记录、带签名的资源链接或凭据提交到仓库。

## 统计口径

`pv`、`uv` 为历史累计，`pv_today`、`uv_today` 为接口快照当天数据；以每条统计的 `timestamp` 为准。不同文章的 UV 不可直接相加作为总读者数。此快照不包含近 30/90 天趋势，也不能从累计值倒推出近期趋势。文章年龄、入口曝光和功能发布时间都会影响阅读量。

## 逐篇审核

1. 阅读正文和必要的附件，对照当前产品、固件及硬件验证适用性。
2. 检查重复内容、失效入口、缺失步骤、过时截图和版本混用。
3. 在 `evidence` 中记录具体章节、事实、版本及验证方式。
4. 选择 `decision`，填写 `targetPath`、`priority`、`priorityRank`、`rationale`、`requiredChanges`、`publicationChecks`，最后改为 `reviewStatus: reviewed`。
5. 执行重构时更新 `implementationStatus` 和 `implementation`；保留尚未完成的检查，说明未采用的旧图/表/附件，不把正文审计状态当作发布批准。

| decision | 含义 |
| --- | --- |
| `retain` | 保留，做必要的格式与语言整理 |
| `rewrite` | 根据当前行为重写 |
| `merge` | 合并到另一篇教程，说明目标章节 |
| `archive` | 仅对旧硬件或固件有价值，保留历史入口 |
| `remove` | 已失效、有明确替代且无独立价值，记录理由 |

低阅读量不能单独作为移除依据；高流量的错误步骤优先重写。修改时间只是排查线索，不等于内容已过时。`remove` 是新站的收录决策，不会删除飞书原文。

`targetPath` 记录主要去向，`secondaryTargetPaths` 记录拆分去向。`relatedArticles` 用稳定的 DOC 编号标记关联来源。不收录时仍须说明归档位置或移除理由。

`priority` 使用 `P0`（电气风险纠正及首发核心路径）、`P1`（主要功能、板型及参考整合）、`P2`（历史资料、扩展案例与社区资源）。同级按 `priorityRank` 排序，全表使用唯一序号 1–44。优先级由具体事实、影响与关注度共同确定；P2 也必须完成发布前检查。
