31 个中文文章中的 138 处 Markdown 图片及 137 个图片放大链接改用相对于文章文件的 `docs/public/images/` 路径。GitHub 可以直接根据分支/fork 的文件树读取图片，不依赖正式站先行发布。教程正文、图片、图注、章节顺序和配图归属保持不变，英文翻译的 sourceHash 未刷新。

直接使用相对 public 路径进行原生构建的试验发现：VitePress 1.6.4 会另行打包图片到 assets，放大链接仍指向不存在的 public 路径，且原尺寸预留信息丢失。现仅在 Markdown 图片和链接渲染阶段，将解析到 public/images 的相对路径转换回 /images；其他文章链接、外部 URL 和附件链接不改写。

验证：全部 138 处图片和 137 个放大链接可解析到实际仓库文件。构建 HTML 的逐页图片路径与变更前源码完全一致，每张图保留宽高，无残留 /public/images 放大链接；assets 中没有重复打包的图片。位图仍为 105 个、22.46 MiB，SVG 为 25 个，图片文件字节未变。原素材摘要、发布图片网址与接线/章节校验记录继续有效；仅更新重写文章的当前输出摘要。
