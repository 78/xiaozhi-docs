# 开发指南

先固定固件和 SDK 版本，完成基础构建，再做板型、音频或工具扩展。代码契约和完整技术规范由固件仓库按版本维护。

## 选择教程 {#guides}

| 教程 | 内容 |
| --- | --- |
| [搭建环境与本地构建](./build-firmware) | 选择匹配的 ESP-IDF 和固件版本，从查询板型到构建、烧录及查看日志。 |
| [修改引脚与自定义板型](./custom-board) | 为自己的接线建立独立板型和构建身份，避免被标准固件覆盖。 |
| [音频处理与 AEC](./audio-and-aec) | 分清设备端、服务端和参考信号，再验证实际对话效果。 |
| [唤醒词与识别方案](./wake-words) | 按芯片、内存和模型选择预置、自定义或外接唤醒。 |
| [用 MCP 控制 GPIO](./mcp-gpio) | 复用固件里的 LampController 示例，验证设备端工具发现与输出电平。 |
| [提示音与语言资源](./custom-prompts) | 按当前 locale 资源与 OGG/Opus 生成流程替换提示音。 |
| [P3 提示音历史方案](./archive/p3-prompts) | 为维护旧固件保留 P3 概念和迁移入口，不用于现行默认资源流程。 |
