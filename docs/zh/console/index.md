<a name="role-and-voice"></a>

## 修改名字、音色与语言模型 {#role-and-voice}

1. 登录[控制台](https://xiaozhi.me/console/)，找到设备实际所属的智能体，打开 **配置**。
2. 在角色与声音设置中修改助手昵称，选择对话语言和音色。先试听音色；需要自己的声音时按[声音复刻](./voice-cloning.md)操作。
3. 需要自定义角色时，启用自定义角色介绍，写明身份、语气和任务。助手昵称是对话角色名称，不会改变设备的离线[唤醒词](../development/wake-words.md)。
4. 在模型与记忆设置中选择当前账号可用的语言模型；灰色选项先查看其资格或限制说明。选择会影响费用和能力，以页面为准。
5. 点击 **保存**，关闭后重新打开，核对选择仍在。让设备开始一轮新对话，检查角色与音色；不要只凭试听成功判断设备已生效。

<a name="speaker-recognition"></a>

## 让智能体识别说话人 {#speaker-recognition}

声纹识别用来区分谁在说话，与“把设备的回答换成某个人的声音”的声音复刻不同。

1. 先用目标设备和同一个智能体说一段清晰、只有一个人讲话的内容，让它产生可选的语音记录。
2. 在智能体 **配置 → 声纹识别** 中选择添加说话人。
3. 在声纹/语音记录下拉框里选择刚才那个人的记录，先试听，避免选成别人的声音或多人的串音。
4. 填写说话人名称和描述。描述可以写“我是小明，是这台设备主人的家人”，让角色理解关系；保存后确认说话人出现在列表里。
5. 开始新对话，分别让已登记和未登记的人讲话，检查实际识别结果。识别不可靠时换一段更清晰的记录再测试。

列表为空时，先检查选中的智能体、是否已有用户语音，以及录音是否能正常播放。可添加数量和描述长度以页面提示为准。声纹会受噪声和录音影响，不把它用作身份认证或付款授权。
