# 音乐、歌词与社区资源

原“开源音乐”文档包含 17 组音频与歌词，明确声明以 MIT 发布由 Suno 等工具生成的作品。迁移时保留原声明与来源，不把它们悄悄改成文档站自己的作品。

## 作品与文件 {#materials}

音频和歌词分开放在文档仓库的素材 Release，站点只提供播放/下载入口。原文件的格式、名称、大小和 SHA-256 随清单保留。

<SourceMaterials article="DOC-41" />

## 使用与核对 {#scope}

- 每首作品核对音频、歌词文件名及内容是否对应，保留提交者/原署名。
- 需要再分发时查看该项原声明，不能因为目录里写“开源”就把其他第三方素材一并套用同一许可。
- 页面可播放/下载不等于设备已经支持某种点歌服务；设备功能以实际服务和固件为准。

本次保留的是原文的授权声明与资产来源，没有把所有曲目逐一确认成自己创作或新增商业授权保证。

## 投稿与维护 {#contribute}

提交作品时附音频、歌词、署名、来源、允许的使用方式及可追溯版本。新的投稿渠道由仓库维护者确认，旧文邮箱不作为自动接收/处理承诺。

音频大文件不要进文档 Git 历史；使用独立 Release，并保留文件校验清单。其他设计资源见[开源硬件](./open-hardware)和[SF32 案例](./projects/sf32lb52-plugin)。
