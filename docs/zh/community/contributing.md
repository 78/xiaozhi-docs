<a name="contributing"></a>

# 参与文档贡献 {#contributing}

你可以修正错误步骤、补充缺少的说明、验证硬件接线，或帮助翻译。小的修正同样有价值。

<a name="report-an-issue"></a>

## 报告问题 {#report-an-issue}

在文章下方点击“反馈文档问题”，提供页面地址、问题位置，以及涉及的设备型号和固件版本。说明你实际看到了什么、原本期望什么。

<a name="submit-a-correction"></a>

## 提交修正 {#submit-a-correction}

1. 点击文章下方的“在 GitHub 编辑此页”。
2. 修改 Markdown 内容并提交 Pull Request。首次参与时，GitHub 会引导你建立自己的副本。
3. 说明修改原因和验证方式。维护者审核后合并，网站会自动更新。

完整写作与提交约定见[仓库贡献指南](https://github.com/78/xiaozhi-docs/blob/main/CONTRIBUTING.md)。

<a name="help-translate"></a>

## 帮助翻译 {#help-translate}

首批新版教程先校对中文。欢迎先反馈实际操作、硬件差异和缺少的步骤；维护者确认中文后，再启动英文翻译。英文占位页不表示已经翻译完成。

中文和英文文章采用相同路径。翻译时统一术语，保留代码、引脚、板型和文件名。界面截图也需要对应语言；仅翻译正文还不够。

欢迎先核对一篇文章。若发现技术事实有误，请同时指出中文原稿中的问题。
