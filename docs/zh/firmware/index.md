# 固件与烧录

先识别芯片、板型变体和镜像类型，再进行安装或升级。历史版本单独归档；大部分设备优先[在线编译并烧录](https://xiaozhi.me/console/firmware-builder)，包括面包板；没有引出 USB 下载接口的设备先按板卡说明处理。

<a name="guides"></a>

## 选择教程 {#guides}

| 教程 | 内容 |
| --- | --- |
| [在线编译与网页烧录](./online-builder.md) | 不用安装 ESP-IDF，为自己的板型生成固件并通过浏览器写入。 |
| [下载与选择固件](./downloads.md) | 按照芯片、板型和变体选择固件，区分当前安装与历史版本。 |
| [烧录与升级](./flashing.md) | 识别镜像类型，选择网页或离线方式烧录，并检查设备是否正常启动。 |
| [v2.6.0 正式固件](./releases/v2.6.0.md) | 查找已发布的固件包，核对面包板、嘉立创 S3 等常见变体。 |
| [v1.9.4 历史固件](./releases/v1.9.4.md) | 维护 v1 旧设备时，按产品名称与芯片选择 v1.9.4。 |
