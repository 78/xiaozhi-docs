# 固件与烧录

先识别芯片、板型变体和镜像类型，再进行安装或升级。历史版本单独归档；当前安装路径从下载或在线编译开始。

## 选择教程 {#guides}

| 教程 | 内容 |
| --- | --- |
| [下载与选择固件](./downloads) | 按照芯片、板型和变体选择固件，区分当前安装与历史版本。 |
| [在线编译与网页烧录](./online-builder) | 不用安装 ESP-IDF，为自己的板型生成固件并通过浏览器写入。 |
| [烧录与升级](./flashing) | 识别镜像类型，选择网页或离线方式烧录，并检查设备是否正常启动。 |
| [v2.5.2 历史固件](./releases/v2.5.2) | 保留明确版本的来源，当前安装回到统一下载页。 |
| [v2.2.4 历史固件](./releases/v2.2.4) | 维护旧设备时查阅 v2.2.4 的下载来源和升级边界。 |
| [v1.9.4 及旧附件索引](./releases/v1.9.4) | 保留旧固件的版本边界和官方发布入口，避免混用分区布局。 |
