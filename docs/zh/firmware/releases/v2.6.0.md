# v2.6.0 正式固件下载

**v2.6.0 已正式发布。** 本页固定到这个版本；完整更新说明与全部板型资产见 [官方 v2.6.0 发布页](https://github.com/78/xiaozhi-esp32/releases/tag/v2.6.0)。

## 优先在线安装 {#online}

大部分设备和面包板可以直接在[小智控制台编译并烧录](https://xiaozhi.me/console/firmware-builder)，按[在线操作指南](../online-builder)选择板型、语言和功能。需要离线文件或复现正式发布的默认配置时，再下载下列固件包。

未引出 USB 下载接口的设备不能仅靠网页完成连接，先按[烧录准备](../flashing#prepare)确认板卡接口。

## 按开发板查找固件 {#download}

按产品名称和芯片找到自己的设备，再核对屏幕、联网方式和硬件修订。点击表格中的完整文件名即可下载 ZIP，无需到 Release 文件列表里猜名字。也可以用浏览器的查找功能（Ctrl+F / ⌘F）搜索产品名或型号。

## 解压后再确认镜像类型 {#install}

1. 保留 ZIP 文件名与版本，解压后检查其中的镜像及说明。
2. 区分完整镜像、OTA 应用镜像和多文件产物，按[镜像类型与写入地址](../flashing#image-types)操作。应用镜像不能直接当作完整镜像写到 `0x0`。
3. GitHub 自动生成的 **Source code** 压缩包是源码，不是编译好的设备固件。
4. 跨分区布局、更换板型或从旧版本回退时，先核对升级边界并准备重新配网；不要默认所有变体都可以直接 OTA。

## 版本与复现 {#version}

在线编译页面显示的版本号相同，源码 Commit 和编译选项仍可能不同。排查问题时同时记录版本、Commit、板型变体与所用下载来源。

完整技术变更和构建要求继续维护在固件仓库：查看 [v2.6.0 源码](https://github.com/78/xiaozhi-esp32/tree/v2.6.0)及[更新说明](https://github.com/78/xiaozhi-esp32/releases/tag/v2.6.0)，需要改代码时转到[本地构建](../../development/build-firmware)。
