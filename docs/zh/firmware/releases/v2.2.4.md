# v2.2.4 历史固件

这是历史版本入口。首次安装请从[固件选择](../downloads)开始；不要把旧资料标题中的“最新版本”理解为今天的推荐版本。

## 适用范围 {#scope}

保留此页供需要复现 v2.2.4、维护旧布局或查找原下载链接的用户使用。原教程围绕 ESP-IDF 5.5.2；现行开发流程已经进入 IDF 6，不能混用两套环境。

## 下载与识别 {#download}

1. 打开[官方 v2.2.4 Release](https://github.com/78/xiaozhi-esp32/releases/tag/v2.2.4)。
2. 对照实物选择芯片、板型和屏幕/通信变体，保留原文件名与版本。
3. 阅读发布说明，区分固件包与 GitHub 自动生成的 Source code 压缩包。
4. 按包内说明识别完整镜像与应用镜像，再按[烧录指南](../flashing)选择工具及地址。

本次核对到该 Release 有 129 个发布资产。这是发布页快照，不代表所有飞书旧包都已经验证为同一份文件；不能找到准确型号时停止试刷，向板卡维护者确认。

## 更新到现行版本 {#upgrade}

先记录现有版本、内存、板型与布局。跨布局或更换硬件时准备完整安装与重新配网；不把旧版应用包写到 `0x0`，也不保证回退一定能 OTA。

::: tip 完成标志
能确认历史文件的版本和板型，知道为何需要它，并保留返回可运行状态的方法。需要当前默认固件时回到[官方下载入口](../downloads)。
:::
