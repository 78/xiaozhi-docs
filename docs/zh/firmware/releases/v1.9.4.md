## 使用前 {#download}

确认旧设备的芯片、板型变体、内存和布局，保存当前可运行的固件来源及恢复方法。找不到精确匹配时联系维护者，不从同系列随便挑一个文件。

源码复现使用该 tag 的 README 和 SDK 说明；不要把现行 IDF 6 环境强套到旧 tag，也不要用旧环境构建新代码。

## 升级与回退 {#verify}

v1 与后续布局可能不同，跨布局不假设可以直接 OTA。先按目标版本确认完整安装、NVS 影响和重新配网流程；回退也同样需要核对。

旧下载资产没有逐个运行过。完成维护需要记录“为何保留此版、适用哪块板、怎样恢复”，而不是仅持有一个 `.bin` 文件。
