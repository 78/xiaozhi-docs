# v1.9.4 历史固件下载

本页只提供 **v1.9.4**，用于维护 v1 旧设备。新设备优先使用 [v2.6.0](./v2.6.0.md) 或[在线编译与烧录](../online-builder.md)。

<a name="scope"></a>

## 适用范围 {#scope}

先确认需要保留 v1 的原因、实际板型、芯片和分区布局。官方说明与源码见 [v1.9.4 发布页](https://github.com/78/xiaozhi-esp32/releases/tag/v1.9.4)。同名板型的 v1、v2 固件也可能采用不同分区，不能只改下载文件名就直接 OTA。

<a name="download"></a>

## 按开发板查找固件 {#download}

以下 **88 个固件包**按产品系列分组。核对产品名称、芯片及变体后，点击完整文件名下载；也可以用 Ctrl+F / ⌘F 搜索型号。解压后按[镜像类型和写入地址](../flashing.md#image-types)安装，不把源码归档当作设备固件。
