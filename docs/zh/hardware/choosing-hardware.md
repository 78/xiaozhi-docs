# 为小智选择硬件

先选择已经有明确适配和接线说明的一套方案，再买模块。便宜、外形相近或芯片同名，都不能代替兼容性核对。

<a name="scope"></a>

## 从用途开始 {#scope}

| 用途 | 建议核对 |
| --- | --- |
| 第一次做语音设备 | [基础 S3 面包板](./breadboard-esp32-s3.md)，器件和固件固定 |
| 更小的低成本设备 | [C3 + ES8311](./breadboard-esp32-c3.md)，不要混用 S3 音频模块 |
| 需要屏幕或拍照 | 选有匹配[彩屏](./displays/st7789.md)/[摄像头](./breadboard-camera.md)方案的硬件 |
| 定制成品 | 结合[设计要点](./design-guidelines.md)与独立板型维护 |

<a name="kits"></a>

## 选好一套，再进入对应教程 {#kits}

- **成品设备**：先在[支持的板型](./supported-boards.md)核对具体型号与固件，已有成品无需另外购买一套面包板模块。
- **基础面包板**：从[完整材料照片与清单](./breadboard-esp32-s3.md#materials)开始，那里有主控、麦克风、功放、喇叭、导线、面包板和屏幕的识别图。
- **小型 C3 / 已有经典 ESP32**：分别进入[C3](./breadboard-esp32-c3.md)和[经典 ESP32](./breadboard-esp32.md)，按各自的模块、接线图与固件搭建。
- **移动联网**：先读[4G 方案的模块、电源与接线图](./breadboard-4g.md)；只是临时外出时，也可先判断 Wi-Fi 手机热点是否满足自己的用途。

<a name="checklist"></a>

## 买之前逐项核对 {#checklist}

- **主控与内存**：完整模组型号、Flash/PSRAM 容量及接口，是否有当前固件适配。
- **麦克风/Codec**：I2S、PDM 或模拟接口、信号方向、供电与声道选择。
- **功放**：输入格式、允许电压、负载阻抗、使能及默认增益电路。
- **显示**：驱动、分辨率、接口、地址、引脚、背光驱动与模块电压。
- **电源与线材**：USB 是否有数据、板上电源路径、峰值负载与可靠接触。

MAX98357A 与 B 不能笼统说“都通用”：数字输入格式不同。扬声器、耳机和有源音箱也不是同一输出负载，详见[音频输出](./audio-output.md)。

<a name="verify"></a>

## 收货后先做什么 {#verify}

检查丝印、封装、排针和资料是否一致，再断电核对接线。优先完成基础设备的启动、显示、录放和对话，增加一个模块就单独测一次。

不要把卖家展示的彩屏图认作自己收到的屏幕规格，也不把“开发板带 5V 排针”推断成任意电池的充电口。

<a name="sources"></a>

## 渠道与资料 {#sources}

器件识别图和具体购买规格随对应搭建教程维护，不在本页把几个模块单独罗列成一套方案。原采购资料中的时效价格、库存和商家质量断言不作为当前承诺。维护者更换渠道时也应维持同一套电气规格，不能只替换购物链接。支持情况见[板型与变体](./supported-boards.md)。
