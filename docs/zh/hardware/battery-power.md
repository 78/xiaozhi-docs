# 电池供电与充电

让面包板小智离开电脑运行，最容易复现的方式是使用成品 USB 移动电源。开发板本身没有电池管理功能时，不要把锂电池接到它的电源脚上。

## 准备工作 {#scope}

本文以 USB 供电的 ESP32-S3 开发板为例。准备已完成[接线](./breadboard-esp32-s3)和[配网](../getting-started/wifi-and-binding)的设备、一条可靠的 USB 线，以及能够提供开发板所需 5V 输出的成品移动电源。

先用电脑或合适的 USB 电源确认设备能正常对话，再更换供电方式。这样可以区分固件问题和电源问题。

## 1. 使用 USB 移动电源 {#usb-power}

1. 记录现有接线和正常工作状态，关闭设备并断开电脑。
2. 保持面包板上的接线不变，将原来的 USB 供电线接到移动电源。
3. 打开移动电源，观察启动提示，等待设备连接已经保存的 Wi-Fi。
4. 先以低音量对话，再测试常用音量。确认联网、播放和待机都能持续工作。
5. 停止使用时关闭移动电源；给移动电源充电按其厂商说明进行。

部分移动电源会在负载较低时自动关机。如果小智待机后断电，检查是否支持低电流模式以及该模式是否限时。不要把能启动一次当作长期供电验证。

::: info 使用范围
移动电源的“边充边放”不是默认能力。需要同时充电和运行时，先确认其厂商明确支持，并验证切换电源时设备是否重启。
:::

## 2. 设备自带电池接口时 {#battery-connector}

只有板卡文档明确列出电池类型、允许电压、接口极性及充电口时，才按该板的说明使用。

| 需要核对 | 确认内容 |
| --- | --- |
| 电池类型 | 单节/多节、化学体系、允许充电电压，与充电芯片匹配 |
| 接口 | 实际正负极；同样外形的插头可能采用相反极性 |
| 保护 | 过充、过放、过流与短路保护由哪里实现 |
| 充电口 | 哪个 USB 口能充电，哪些接口只用于供电或数据 |
| 电源切换 | USB 与电池如何切换，是否允许同时接入 |

设备没有标明电池接口时，不把 `3V3`、`5V` 或 `GND` 排针当作充电接口。

## 3. 裸电芯与升压模块的边界 {#custom-power}

定制方案需要完整的“电池保护 → 充电及电源路径管理 → 稳压/升压 → 负载”设计。标有 `B+ / B−` 只说明某处的电池连接关系，不能证明模块包含全部功能。

实施前应有确定的模块型号、原理图和这些测试结果：

- 在连接开发板前，测得极性和输出电压符合要求。
- 对话、Wi-Fi 发射和最大计划音量下，电压及温升仍在器件规定范围内。
- USB 接入/断开、电池低电量和充电期间，不发生不允许的回灌或电源冲突。
- 连接器和机械固定不会使带电端子接触或短路。

这部分需要按所选电路进行工程复核。不要凭颜色猜极性、通过“不亮”判断反接，或剪开电池引线通电试错。

对 ESP32-S3-DevKitC-1，厂商将 USB、5V 排针、3V3 排针列为互斥的供电方式。该规定不意味着板子能给锂电池充电。[开发板供电说明](https://documentation.espressif.com/esp-dev-kits/en/latest/esp32s3/esp32-s3-devkitc-1/user_guide_v1.1.html)。

## 怎么确认完成 {#verify}

::: tip 完成标志
设备在计划使用的音量下可以连续对话，待机后仍能唤醒；充电与使用方式符合电源产品说明。续航应以实际负载测量，不能只根据电池容量估算承诺。
:::

## 常见问题 {#troubleshooting}

| 现象 | 排查顺序 |
| --- | --- |
| 完全不开机 | 断开负载，检查移动电源开关、线材与输出；不要直接反接试一次 |
| 音量一大就重启 | 降低音量，换可靠供电线/电源，检查功放负载和接触 |
| 待机几分钟就关机 | 检查移动电源低负载自动关断 |
| 插上充电器就重启 | 确认电源切换/边充边用支持情况，不用反复重启代替电路核验 |
