# Music, lyrics, and community resources

This collection contains 17 audio/lyrics pairs. Contributors state that the works are released under MIT and generated with tools such as Suno. Check each item's licensing notice before use or redistribution.

<a name="materials"></a>

## Works and files {#materials}

Audio and lyrics are distributed separately through a documentation-assets Release. This site provides playback and download links. The inventory retains original formats, names, sizes, and SHA-256 checksums.

<SourceMaterials article="DOC-41" />

<a name="scope"></a>

## Use and verification {#scope}

- Check that each audio file and lyric file match by name and content, retaining contributor/original credits.
- Review each item's own notice before redistribution. An “open source” directory label does not apply one license to unrelated third-party assets.
- Website playback/download support does not establish that a device supports a music-request service. Device capabilities depend on the actual service and firmware.

Licensing notices come from the respective contributors. Check permission for your intended use where third-party rights are involved.

<a name="contribute"></a>

## Contributions and maintenance {#contribute}

Include audio, lyrics, credits, source, permitted uses, and a traceable version with a submission. Follow the repository's current contribution instructions.

Keep large audio files out of the documentation Git history. Use a separate Release with a checksum inventory. For design resources, see [Open hardware](./open-hardware.md) and [SF32](./projects/sf32lb52-plugin.md).
